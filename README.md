## 어떤 앱인가요?

하루를 관리하는 데 필요한 것만 담았습니다. 시험 준비로 지친 하루를 **작은 체크 하나씩** 밀어주는(nudge) 것이 이 앱의 목적입니다. 책 *Nudge*(Thaler & Sunstein)의 표지처럼, 주황 화살표가 오늘을 살짝 밀어줍니다.

- 📱 **홈 화면 앱처럼** — iOS Safari에서 "홈 화면에 추가"하면 전체 화면 앱으로 실행됩니다
- 🔒 **데이터는 내 기기에만** — 별도 서버·계정 없이 브라우저에 저장됩니다
- 🌙 **라이트/다크/흑백** 테마와 부드러운 iOS 스타일 애니메이션
- 📆 **구글 캘린더 연동** — 하루가 지나면 완료한 일정이 내 캘린더에 자동 기록되고, Apple 캘린더에서도 구독할 수 있습니다

## 주요 기능

| 탭 | 하는 일 |
|---|---|
| **오늘** | 요일별 반복 일정 체크리스트, 진행 링, 자습 타이머(일시정지·시간 조정), 점심 자습 결정 |
| **학습** | 과목 → 챕터 → 강의 관리, 스와이프 삭제, 터치로 이름 수정, 오늘의 목표와 진도율 |
| **운동** | 요일별 부위 분할 + 매일 루틴, 루틴 완료 캘린더(잔디 느낌의 성취 기록) |
| **통계** | 주간/월간 자습 시간, 세션 수, 진도율, 성공 기준 판정 |
| **설정** | 테마, 알림, 일정 편집, 학습/운동 설정, 구글 캘린더 동기화 |

## 디자인

UI/UX는 Microsoft의 디자인 시스템 [**Fluent 2**](https://fluent2.microsoft.design/)(특히 [iOS 컴포넌트](https://fluent2.microsoft.design/components/ios))를 참고했습니다. iOS 네이티브 앱처럼 자연스러운 시트 전환, 스프링 애니메이션, 라이트/다크 테마를 지향합니다.

## 시작하기

1. iPhone Safari로 **[홈페이지](https://hojunkim02.github.io/nudge-app/)** 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 Nudge 아이콘으로 실행

> 💡 데모 버전에서는 한 달치 예시 데이터가 채워진 상태로 시작합니다.
